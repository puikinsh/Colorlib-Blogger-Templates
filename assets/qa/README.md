# Original media QA fixtures

`media-signal.wav` is an original 12-second, mono 16kHz PCM signal: a brief, low-amplitude 440Hz tone once each second with silence between tones. It contains no speech, music, personal information or third-party recordings. Generated by `python3 tools/make_audio_fixture.py` and licensed with this repository under GPL v3.

`media-signal.mp3` is the same signal encoded using the locally installed FFmpeg/libmp3lame encoder. Regenerate with:

```sh
ffmpeg -y -i assets/qa/media-signal.wav -map_metadata -1 -codec:a libmp3lame -q:a 7 assets/qa/media-signal.mp3
```

FFmpeg is only needed to regenerate the checked-in MP3; normal builds and users need no encoder. These are format/controls fixtures, not podcast content or proof of audible output. Browser tests must start playback through native controls, without autoplay.
