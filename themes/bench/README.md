## Download

**Choose this exact package:** `bench-blogger-template-0.1.0-preview.5.zip`

[Open the GitHub release downloads](https://github.com/puikinsh/Colorlib-Blogger-Templates/releases/tag/v0.1.0-preview.5) and expand **Assets** if needed. Select **`bench-blogger-template-0.1.0-preview.5.zip`** from the list.

Use the named template package. GitHub's **Source code (zip)** and **Code → Download ZIP** contain the development repository, rather than the installable theme package.

## Which files do I need?

After extracting the package, open **`Bench-Blogger-Template/`**.

| File | Use |
| --- | --- |
| **`Bench-Blogger-Template.xml`** | **Install this file in Blogger → Theme → Restore → Upload.** |
| `Bench Demo Content.xml` | Optional sample posts: Blogger → Settings → Manage Blog → Import content. |
| `post-template.html` | Optional starting layout to copy into a post's HTML editor. |
| `README.md` | Package setup and customization instructions. |
| `ASSETS.md` | Artwork and photography credits and license information. |

Do not upload the ZIP or the demo-content XML as your theme.

## Installation

1. Back up your current theme from **Blogger → Theme → menu beside Customize → Backup**.
2. Extract **`bench-blogger-template-0.1.0-preview.5.zip`** on your computer.
3. In **Theme → menu beside Customize → Restore → Upload**, select **`Bench-Blogger-Template.xml`** inside **`Bench-Blogger-Template/`**.
4. If you want sample posts, use **Settings → Manage Blog → Import content** and choose **`Bench Demo Content.xml`**. Importing sample posts is optional.
5. In **Layout**, edit your header, pages, homepage introduction and visual notebook. Adjust colors through **Theme → Customize → Advanced**.

## What you can publish

Review pages for specifications, comparisons, benefits and trade-offs.

The theme also includes responsive article layouts, photo galleries, native Older/Newer navigation, Blogger comments, search and editable homepage widgets. Replace sample text and use images you have permission to publish.
