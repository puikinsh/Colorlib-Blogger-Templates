# Changelog

Changes follow Keep a Changelog. Development previews have not been released as production products.

## [Unreleased] — 0.1.0 development collection

### Changed

- Redesigned Launchpad and Lesson with shadcn-inspired product-journal/documentation systems, and Bench and Studio with Tailwind-inspired review/portfolio layouts.
- Shared each redesigned home composition between Blogger XML and local previews; versioned preview asset URLs to prevent stale designs.

### Added

- Twenty independent niche themes with shared Blogger widgets, native pagination, comments, metadata and responsive foundations.
- Twenty niche article formats, owner-editable homepage introductions, twelve sample posts and original vector cover sets per theme.
- Conditional recipe markup, article contents navigation, print/checklist controls, local budget arithmetic and optional click-to-load video.
- Deterministic preview packages, local galleries and responsive review panels, build/schema checks, 45 automated regressions and a CI validation workflow.
- Architecture, editing, contributor and release-validation documentation.

### Fixed

- Long headings overflowing the narrowest layout.
- Demo import identifiers colliding across different themes.
- Single-theme rebuilds removing other gallery entries and package checksums.
- Calculator inputs submitting through a form when JavaScript is unavailable.

### Pending

- Dedicated Blogger lab approval, platform imports and public asset/demo hosting.
- Per-theme editorial, accessibility and performance acceptance before a production release.
